# راهِ حفظ — برنامه‌ی حفظ و مرور قرآن

یک وب‌اپلیکیشن کامل (PWA) برای برنامه‌ریزی، پیگیری پیشرفت و مرورِ فاصله‌دارِ حفظ قرآن.
هیچ نصب یا سرور اضافه‌ای لازم نیست؛ فقط با VS Code باز و اجرا می‌شود.

## اجرا با VS Code (بدون نیاز به نصب چیز دیگری)

1. پوشه‌ی `quran-hifz` را در VS Code باز کنید.
2. اکستنشن رایگان **Live Server** را از تب Extensions نصب کنید (فقط یک‌بار، جست‌وجوی `Live Server` توسط `ritwickdey`).
3. روی فایل `index.html` راست‌کلیک کنید و **Open with Live Server** را بزنید.
4. مرورگر باز می‌شود و برنامه اجرا می‌شود.

> اگر نمی‌خواهید حتی اکستنشن نصب کنید: کافی است فایل `index.html` را مستقیم در مرورگر (کروم/سافاری) باز کنید. تنها تفاوت این است که سرویس‌ورکر (حالت آفلاین کامل) روی `file://` فعال نمی‌شود، ولی کل برنامه به‌درستی کار می‌کند.

## نصب روی گوشی (مثل یک اپ واقعی)

اگر پروژه را روی یک هاست ساده (مثلاً GitHub Pages، Netlify یا حتی همان Live Server در شبکه‌ی خانگی) بالا بیاورید:
- **اندروید (کروم):** منوی سه‌نقطه ⟵ «Add to Home screen»
- **آیفون (سافاری):** دکمه‌ی Share ⟵ «Add to Home Screen»

برنامه به‌صورت آیکون مستقل روی صفحه‌ی اصلی گوشی نصب می‌شود و بدون نوار آدرس مرورگر باز می‌شود.

## ساختار فایل‌ها

```
quran-hifz/
├── index.html        صفحه‌ی اصلی و تمام بخش‌ها (داشبورد، سوره‌ها، برنامه، مرور، تنظیمات)
├── manifest.json      تنظیمات نصب PWA
├── sw.js              سرویس‌ورکر برای کارکرد آفلاین
├── css/style.css      استایل کامل برنامه
├── js/data.js         فهرست ۱۱۴ سوره با تعداد آیات
├── js/app.js          کل منطق برنامه
└── icons/             آیکون‌های برنامه
```

## امکانات

- **داشبورد**: درصد کلی حفظ قرآن (با نمای ستاره‌ی هشت‌پر)، استریک روزهای پیاپی، هدف امروز
- **فهرست سوره‌ها**: جست‌وجو، وضعیت هر سوره (شروع‌نشده / در حال حفظ / حفظ‌کامل)، ثبت پیشرفت آیه‌به‌آیه
- **برنامه**: انتخاب سطح (مبتدی/متوسط/پیشرفته)، تعیین هدف روزانه، پیش‌بینی زمان اتمام حفظ کل قرآن
- **مرور فاصله‌دار**: هر سوره‌ی حفظ‌شده طبق الگوی یادگیری فاصله‌دار (۱، ۳، ۷، ۱۶، ۳۵، ۹۰ روز) دوباره برای مرور یادآوری می‌شود
- **تنظیمات**: نام کاربر، اندازه‌ی قلم، پاک‌کردن کامل داده‌ها

## ذخیره‌سازی داده‌ها

تمام اطلاعات (پیشرفت، برنامه، تنظیمات) در `localStorage` همان مرورگر/گوشی ذخیره می‌شود — نیازی به اینترنت یا سرور نیست.
توجه: اگر Cache/Storage مرورگر پاک شود یا از مرورگر دیگری باز کنید، پیشرفت قبلی دیده نمی‌شود.

## توسعه‌های بعدی پیشنهادی

- افزودن فایل صوتی تلاوت برای هر سوره
- افزودن متن و ترجمه‌ی آیات
- همگام‌سازی ابری بین چند دستگاه
